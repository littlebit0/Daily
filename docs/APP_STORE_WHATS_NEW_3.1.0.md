# DailyCalendar 3.1.0 이 버전에서 업그레이드된 사항

DailyCalendar 3.1.0에서는 더욱 편리한 일정 관리를 위해 다음 기능을 추가하고
안정성을 개선했습니다.

- Siri를 통한 일정 조회, 추가, 수정 및 삭제 지원
- Siri 작업 기록과 실행 결과 확인 기능 추가
- 한국어, 영어, 일본어, 중국어 번체 지원
- 시스템 언어 자동 적용 및 앱 내 언어 선택 지원
- 주간·일간 캘린더에 시간표형 일정 보기 추가
- Google Drive 백업 및 동기화 안정성 개선
- 일정 알림과 위젯 갱신 안정성 향상
- 캘린더 탐색과 화면 전환 성능 개선
- 앱 아이콘 디자인 변경
- 기타 UI 오류와 안정성 문제 수정
