# DailyCalendar 3.3.1 릴리스 노트

## 릴리스 기준

- 앱 표시 버전 및 빌드: `3.3.1 (3.3.1)`
- Apple 앱 번들 ID: `com.littlebit0.daily`
- Apple 위젯 번들 ID: `com.littlebit0.daily.widgets`
- 비교 기준: `3.1.0`

## 주요 변경 사항

- 모든 일정에 Todo 완료 상태를 추가하고 빠른 보기, 캘린더, 일정 상세와 Apple
  위젯에서 완료 상태를 관리할 수 있도록 개선했습니다.
- 기존 사용자 데이터를 원격 복원, 안전 스냅샷, 검증과 원자적 교체 순서로
  마이그레이션하며 실패하면 원본 데이터를 유지합니다.
- 일정 날짜 이동과 날짜별 수동 순서, 분류 순서 및 분류·시간 우선 정렬,
  공휴일 색상과 날짜 배경 설정을 추가했습니다.
- 반복 일정 종료일 누락과 한 발생분의 Todo 완료가 다른 발생분에 적용되던
  문제를 수정했습니다.
- Apple 위젯의 Todo 체크, 즉시 갱신과 라이트·다크 테마 대응을 개선했습니다.
- Google 로그인 사용자가 앱에서 내용을 확인한 뒤 버그를 제보할 수 있도록
  지원하고 연락용 이메일과 공개 GitHub 이슈를 분리했습니다.
- Daily 소개, 익명 분석 선택, Siri 설정, 알림·알람 권한과 계정 선택을 단계형
  온보딩으로 정리했습니다.
- 빠른 보기, 설정, 검색·필터, 일정 편집, 캘린더 가져오기와 Siri 기록 화면을
  Apple 플랫폼에 어울리는 공통 UI로 개선했습니다.
- 계정 연결, 백업·복원, 로그아웃과 계정 삭제 버튼의 디자인과 상태 표시를
  통일하고 개발 확인용 알림 테스트 기능만 제거했습니다.
- 캘린더 상·하단 조작부의 외곽선을 정리하고 오늘, 이동, 필터, 설정, 빠른
  보기, 달력과 AI 아이콘을 더 명확한 형태로 교체했습니다.
- macOS 월간 및 주간·일간 목록/스케줄의 트랙패드 페이지 이동 회귀를
  수정했습니다.
- 선택형 익명 사용성 분석은 기본 비활성화로 제공하며 사용자가 동의한
  Release 빌드에서만 운영 집계 서버로 전송합니다. 일정 내용, 검색어, 계정,
  광고 식별자와 영구 기기 식별자는 분석에 포함하지 않습니다.

## GitHub 배포 파일

GitHub Actions는 `v3.3.1` 릴리스에서 다음 공개 검증용 파일을 생성합니다.

- `daily-ios-3.3.1-unsigned.ipa`
- `daily-macos-3.3.1-unsigned.dmg`

GitHub의 unsigned IPA와 DMG는 App Store 제출 파일이 아닙니다. Transporter
제출용 서명 IPA/PKG는 로컬 `dist/transporter-upload/3.3.1`에만 생성합니다.
