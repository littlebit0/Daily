# Daily 초기 기획안

## 제품 개요

Daily는 혼자 사용하는 개인용 독립 캘린더 앱이다. 기존 Apple Calendar, Google Calendar, Outlook Calendar와 연결하지 않고 자체 데이터만 관리한다.

앱의 첫 화면은 항상 월간 달력이다. 주간 뷰, 추천 알고리즘, 투두 기능은 초기 버전에 넣지 않는다. 사용자는 앱을 열자마자 이번 달 전체 일정을 한눈에 확인할 수 있어야 한다.

## UX 원칙

- 앱 실행 즉시 월간 달력을 보여준다.
- 일정이 있는 날을 점 하나로 표시하지 않는다.
- 각 날짜 칸 안에 일정 제목을 짧은 플래그 바 형태로 보여준다.
- 시간 일정은 `09:00 병원`처럼 표시한다.
- 종일 일정은 제목만 표시한다.
- 모바일은 날짜당 최대 3개 일정을 표시하고 초과분은 `+N`으로 보여준다.
- 태블릿과 데스크톱은 가능한 만큼 더 많은 일정을 표시한다.
- 날짜를 누르면 해당 날짜의 세부 일정이 열린다.
- 채팅 입력창은 항상 화면에 보인다.

## 플랫폼 방향

처음에는 Apple 생태계 중심의 CloudKit도 검토했지만, 이후 Windows와 Android도 배포 대상에 포함되면서 Firebase 기반 동기화로 변경했다.

최종 기술 방향:

- 앱 프레임워크: Flutter
- 로컬 저장소: drift + SQLite
- 실시간 동기화: Firebase Auth + Cloud Firestore
- AI 일정 해석: 규칙 기반 파서 우선, Gemini API 선택 사용
- 알림: 로컬 알림
- 백업: 로컬 SQLite 파일 백업/복원, Firestore 원격 데이터 보관

## 일정 입력

사용자는 채팅처럼 자연어를 입력해서 일정을 만들 수 있다.

AI 없이 처리할 단순 입력:

- `내일 3시 병원`
- `5월 20일 오후 2시 회의`
- `오늘 저녁 7시 약속`

AI가 필요한 입력:

- 날짜와 시간이 복잡하게 섞인 문장
- 여러 조건이 포함된 문장
- 카테고리 추정이 필요한 일정

AI 결과는 바로 저장하지 않고 확인 카드로 보여주는 방향으로 설계했다.

## 알림

- 기본 일정 알림: 일정 시작 1시간 전
- 아침 브리핑: 오전 8시
- 아침 브리핑 시간은 설정에서 변경 가능
- 일정 수정 시 기존 알림 갱신
- 일정 삭제 시 기존 알림 취소

## 보류 항목

- 투두
- 주간 뷰
- 일간 뷰
- 기존 캘린더 연동
- 공유 캘린더
- 단축키
- 앱 잠금

## MVP 성공 기준

- 앱을 열면 월간 달력이 바로 뜬다.
- 일정이 날짜 칸에 플래그 바로 보인다.
- 날짜를 누르면 세부 일정이 보인다.
- 채팅 입력으로 일정을 등록할 수 있다.
- 단순 자연어는 규칙 기반으로 처리된다.
- 복잡한 자연어는 Gemini API로 해석할 수 있다.
- 반복 일정을 만들 수 있다.
- 기본 1시간 전 알림과 오전 8시 브리핑이 예약된다.
- 여러 플랫폼에서 같은 계정으로 일정이 동기화된다.
- 로컬 백업과 복원이 가능하다.
- 검색으로 일정을 찾을 수 있다.
