# Daily 기능 로드맵

작성일: 2026-05-24
최근 갱신: 2026-08-03

현재 제품 기준은 `3.0.1`이다. 아래 1.1.0 항목은 당시 계획을 보존한 이력이며,
현재 기능 및 배포 상태는 `README.md`, `PROJECT_ANALYSIS.md`,
`docs/PROGRESS_STATUS.md`를 기준으로 한다.

이 문서는 삼성 캘린더와의 비교 이후 확정한 Daily의 후속 기능 범위를 정리한다. Daily의 핵심 방향은 범용 캘린더 전체를 따라가는 것이 아니라, 월간/주간 화면에서 개인 일정을 한눈에 읽기 쉽게 만드는 데 둔다.

## 1.1.0 구현 완료 기능

### 1. 월간 달력 가독성 옵션

- 일정 제목 표시 밀도 옵션을 제공한다.
- 하루 일정 표시 줄 수를 사용자가 조절할 수 있게 한다.
- 긴 제목 표시 우선순위를 개선한다.
- 분류별 표시/숨김 토글을 제공한다.
- 목적: 월간 달력에서 일정 제목을 더 많이, 더 쉽게 읽게 만든다.

### 2. 월간 검색/필터

- 이번 달 일정 검색을 제공한다.
- 제목, 메모, 장소 검색을 지원한다.
- 분류별 필터를 지원한다.
- D-day 일정만 보기 옵션을 제공한다.
- 공휴일 표시/숨김 옵션을 제공한다.

### 3. 동기화 상태 센터

- 마지막 동기화 시간을 표시한다.
- 업로드/다운로드 진행 상태를 표시한다.
- 동기화 실패 사유를 사용자에게 명확히 보여준다.
- 수동 재시도 버튼을 제공한다.
- 충돌이 발생한 경우 복구 안내를 제공한다.

### 4. Android 홈 화면 위젯

- 월간 미니 캘린더 위젯 진입점을 제공한다.
- 오늘 일정 위젯 진입점을 제공한다.
- D-day 위젯 진입점을 제공한다.
- 현재 위젯은 앱 실행 진입점 중심이며, 실제 일정 데이터 표시 브리지는 후속 고도화 항목으로 둔다.

### 5. Windows 트레이 미니 캘린더

- Windows 트레이 아이콘 클릭 시 미니 캘린더를 표시한다.
- 오늘 일정을 바로 확인할 수 있게 한다.
- 빠른 일정 추가 진입점을 제공한다.
- 기존 백그라운드 실행/알림 동작과 충돌하지 않게 설계한다.

### 6. 반복 일정 편집 UX 강화

- 이 일정만 수정.
- 이후 일정 모두 수정.
- 전체 반복 일정 수정.
- 반복 예외 날짜 설정.
- 반복 일정 삭제 시에도 동일한 범위 선택 UX를 제공한다.

### 7. 주간/월간 보기 토글

- 주간 보기를 먼저 보여줄 수 있게 한다.
- 주간 보기에서 월간 보기로 전환하는 토글을 제공한다.
- 월간 보기에서도 다시 주간 보기로 돌아갈 수 있게 한다.
- 설정에서 기본 시작 보기를 선택할 수 있게 하는 방안을 검토한다.
- 주간 보기는 Daily의 플래그 가독성을 유지하되, 한 주의 일정 흐름을 더 크게 보여주는 방향으로 설계한다.

### 8. 일간 보기

- 날짜 상세 패널을 발전시켜 일간 보기로 확장한다.
- 하루 일정을 시간순으로 정리한다.
- 종일 일정, 시간 일정, D-day, 알림 상태를 구분해서 보여준다.
- 모바일에서는 하단 시트 또는 전용 일간 화면으로 제공한다.

### 9. 일정 상세 정보 확장

- 메모 필드를 강화한다.
- 장소 필드를 강화한다.
- URL/링크 필드를 추가한다.
- 월간/주간 플래그에는 제목 중심으로 표시하고, 상세 화면에서 부가 정보를 보여준다.

### 10. 앱 잠금

- 앱 잠금은 선택 기능으로 제공한다.
- 잠금 방식은 PIN을 우선 검토한다.
- 플랫폼에서 가능한 경우 생체 인증을 추가 검토한다.
- 잠금은 앱 실행과 백그라운드 복귀 시점에 적용할 수 있게 설계한다.

### 11. 비공개 일정 기능 폐기

- 개발 과정에서 비공개 일정 관련 모델, 저장 필드, 설정, 화면 동작을 제거했다.
- 현재 로드맵에는 포함하지 않으며 실제 사용자 요구가 확인될 때만 새 설계로
  다시 검토한다.

### 12. 일정별 날씨 표시

- 모든 일정에 날씨를 강제하지 않는다.
- 일정마다 선택적으로 날씨 정보를 붙일 수 있게 한다.
- 예시: `야구경기 - 날씨: 흐림`
- 외부 날씨 API 연동 전 단계로 사용자가 직접 입력하는 방식을 제공한다.

## 보류 기능

아래 항목은 현재 단계에서는 진행하지 않고 보류한다.

- Google Calendar 읽기 전용 가져오기.
- ICS 가져오기/내보내기.
- 한국어 자연어 빠른 입력 고도화.
- AI 기반 일정 검색.
- TODO/체크리스트.
- 알림 스누즈.
- 로컬 백업/복원 고도화.
- 공유 캘린더.
- 참석자 초대, 회의실, 이메일 초대.
- iCloud, 삼성 계정, Outlook 계정을 동시에 연결하는 실시간 동기화.
