# DailyCalendar 3.0.1 이 버전에서 업그레이드된 사항

아래 문안은 App Store에 공개된 `2.7.1`과 제출 후보 `3.0.1`을 비교해
사용자가 실제로 확인할 수 있는 변경 사항을 정리한 것이다.

## iOS

DailyCalendar 3.0.1은 캘린더 탐색, 위젯, 일정 알람, 외부 캘린더 가져오기,
동기화와 앱 보호 기능을 크게 확장한 업데이트입니다.

- 월간 캘린더에서 좌우 슬라이드와 상하 연속 스크롤 방식을 선택할 수
  있습니다. 상하 스크롤에서는 요일을 고정하고 월 경계를 명확히 표시합니다.
- 1년의 12개 달을 작은 달력으로 한눈에 확인하고 이전·다음 연도로 자연스럽게
  이동할 수 있는 연간 보기를 추가했습니다.
- 주·월·일 보기와 빠른 보기·달력·AI를 전환하는 하단 슬라이드 조작을
  추가하고, 화면 이동 애니메이션과 선택 상태를 개선했습니다.
- Apple 캘린더와 Google 캘린더에서 일정을 가져올 수 있습니다. 일정 제목,
  메모, 장소, 시간, 반복, 알림과 원본 캘린더의 이름·색상을 함께 반영하며,
  같은 일정을 다시 가져올 때 중복 생성을 방지합니다.
- 분류별 일정 표시 여부를 선택할 수 있고, 기본 색상 외에 직접 드래그하거나
  RGB 값을 입력하는 사용자 지정 색상을 추가했습니다.
- 홈 화면 위젯에서 오늘 일정, 7일 일정, 월간 일정과 D-day를 확인할 수
  있습니다. 여러 날에 걸친 일정은 이어진 하나의 일정으로 표시됩니다.
- 잠금 화면에 다음 일정, 남은 일정 수, 오늘 일정 위젯을 추가했습니다.
- 일정별로 기존 알림 또는 시스템 알람을 선택할 수 있습니다. 시간 일정은
  시작 시각, 종일 일정은 지정한 시각에 울리며 중지와 10분 뒤 다시 알림을
  지원합니다. 일정 수정·삭제 시 예약도 함께 갱신됩니다.
- 앱 잠금을 PIN 없음, Daily PIN, Apple 시스템 인증 방식 중에서 선택할 수
  있습니다. PIN 잠금은 Face ID 또는 Touch ID를 보조 잠금 해제로 사용할 수
  있습니다.
- Google Drive 백업과 복원을 분리하고, 다른 기기에서 변경된 데이터를 앱
  시작 또는 복귀 시 감지하도록 개선했습니다. 일정 변경은 필요한 항목만
  백업하며 동기화 충돌과 분류 색상 불일치 문제를 보완했습니다.
- Apple 로그인은 Google 로그인을 요구하지 않으며, 사용 가능한 기존 Google
  세션만 조용히 복원합니다. 로그아웃 시 기기 데이터는 정리하고 Drive 백업은
  유지합니다.
- 자동·화이트·다크 테마, 기본·크게·더 크게 글자 크기, 주 시작 요일 등의
  설정을 슬라이드형 선택 방식으로 정리하고 계정·알림 설정을 별도 화면으로
  구분했습니다.
- 전체 다크 모드와 첫 실행 화면을 개선하고, 누락되던 다크 테마 이미지를
  수정했습니다.
- 이전·다음 달을 잇는 범위 선택, 빈 날짜 선택, 연간 보기 이동, 검색 전환,
  빠른 보기 표시와 연속 일정 모양 등의 오류를 수정했습니다.
- 검색 전환, 상하 월 스크롤, 연간 보기, 반복 일정 계산과 위젯 갱신 성능을
  최적화했습니다. 지원 기기에서는 시스템 상태에 맞춰 ProMotion 주사율을
  동적으로 사용합니다.

## macOS

DailyCalendar 3.0.1은 넓은 화면, 마우스와 트랙패드 사용에 맞춰 캘린더,
위젯, 동기화와 앱 보호 기능을 전반적으로 확장한 업데이트입니다.

- 월간 캘린더에서 좌우 이동과 상하 연속 스크롤 방식을 선택할 수 있습니다.
  상하 스크롤에서는 요일을 고정하고 월 경계를 명확히 표시합니다.
- 1년의 12개 달을 작은 달력으로 확인하는 연간 보기를 추가했습니다. 넓은
  창에서는 한 줄에 두 해를 배치하고, 창 크기에 따라 표시 정보량을 조절합니다.
- 빠른 보기·주·월·일 화면 전환 애니메이션을 추가하고 상단 도구 막대는 이동
  중에도 고정되도록 개선했습니다.
- Google 캘린더에서 일정과 원본 캘린더의 이름·색상, 반복, 알림 정보를
  가져올 수 있으며 같은 일정의 중복 생성을 방지합니다.
- 분류별 일정 표시 여부와 직접 드래그하거나 RGB 값을 입력하는 사용자 지정
  색상을 추가했습니다.
- 데스크톱 및 알림 센터 위젯에서 오늘 일정, 7일 일정, 월간 일정과 D-day를
  확인할 수 있습니다. 여러 날 일정은 이어진 하나의 막대로 표시됩니다.
- macOS 알림 센터를 이용한 일정별 알람, 중지와 10분 뒤 다시 알림을
  지원하며 일정 수정·삭제 시 예약도 함께 갱신됩니다.
- 앱 잠금을 PIN 없음, Daily PIN, Apple 시스템 인증 방식 중에서 선택할 수
  있습니다. PIN은 키보드로 입력할 수 있고 Touch ID, Apple Watch 또는 시스템
  암호 인증 흐름을 개선했습니다.
- Google 계정 연결 상태와 Drive 인증 상태를 구분해 표시하고, 만료된 연결의
  재인증 및 자동 세션 복원을 개선했습니다.
- Google Drive 백업과 복원을 분리하고, 다른 기기의 변경 감지, 항목별 백업,
  충돌 처리, 실패 재시도와 분류 색상 동기화 안정성을 개선했습니다.
- 자동·화이트·다크 테마, 글자 크기, 주 시작 요일과 달력 이동 방식 설정을
  정리하고 계정·알림 설정을 별도 화면으로 구분했습니다.
- 전체 다크 모드와 첫 실행 화면을 개선하고 가장 어두운 배경을 검은색으로
  조정했습니다.
- 빈 날짜 선택, 월 경계를 넘는 범위 선택, 연간 보기 이동, Google 재연결,
  잠금 반복 인증과 여러 화면 표시 오류를 수정했습니다.
- 마우스 휠 스크롤을 부드럽게 만들고, 연간 보기 크기 변경, 검색 전환,
  반복 일정 계산과 위젯 갱신 성능을 최적화했습니다. 지원 디스플레이에서는
  시스템의 동적 고주사율을 사용합니다.
